## Projeto em destaque

### Artefatos DK RP

Ferramenta desktop para facilitar o download e preparação dos Artifacts do FiveM / FXServer.

Principais recursos:

* consulta automática dos builds oficiais;
* versão recomendada e versão mais recente;
* download automático;

* gerador configurável de `START.bat`;
* seleção de `server.cfg`;
* histórico de downloads;
* configurações persistentes;
* interface desktop utilizando Electron.

**Tecnologias:**
`Electron` `Node.js` `JavaScript` `HTML` `CSS`

## Como trabalho

Meu fluxo normalmente passa por quatro pontos:

**Análise → Implementação → Testes → Manutenção**

Antes de alterar um projeto existente, procuro entender dependências, integrações e possíveis efeitos colaterais.

Alguns princípios que mantenho no desenvolvimento:

* código legível;
* estrutura organizada;
* evitar dependências desnecessárias;
* resolver a causa do problema;
* preservar compatibilidade quando necessário;
* documentar decisões importantes;
* testar antes de considerar uma tarefa concluída.
